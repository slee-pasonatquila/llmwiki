# LLM Wiki Master Index

本ドキュメントは、プロジェクト全体の構造化ナレッジ（Google OKF v0.2 準拠）を一覧化したマスターインデックスです。
段階的な知識開示（Progressive Disclosure）を支援し、人間と AI エージェントが目的の設計・仕様に迅速にアクセスできるようにします。

* [03. 概要設計 (Basic / Architecture Designs)](03_basic_designs/index.md) - システム構成、認証アーキテクチャ、インフラ設計
* [04. 詳細設計 (Detailed Designs)](04_detailed_designs/index.md) - テーブル定義 (DB)、API 仕様、詳細ロジック
* [05. 設計決定記録 (Architecture Decision Records - ADR)](05_decisions/index.md) - アーキテクチャ決定経緯・技術選定理由
