# 技術選定検討ミーティング議事録

* 日時: 2026-08-10 14:00-15:30
* 参加者: アーキテクト, バックエンドリード, インフラ担当
* アジェンダ: 認証基盤のセッション管理方式の選定

## 議論内容
1. RDBMS セッション管理の課題:
   - 大量アクセス時に DB コネクション枯渇のリスク。
2. JWT ステートレス認証のメリット:
   - 各マイクロサービス / API Gateway が自律的に署名検証できるためスケールアウトが容易。
3. 結論:
   - Access Token は 15 分有効の JWT、Refresh Token は Redis 管理のローテーション方式を採用することに合意。
